# DSA Python Learning Track (Real-Job Focus)

This folder is a full study track based on your weekly syllabus, but implemented in **Python** with practical scenarios.

## How to use this track

1. Read each module header and scenario.
2. Run the file.
3. Trace outputs and edit values.
4. Implement each `TODO` function from scratch.
5. Re-run and compare your output with the built-in solution path.

## Run commands

```bash
cd DSA_Python
python module02_data_structures_intro.py
python module03_arrays.py
python module04_sorting.py
python module05_recursion.py
python module06_stacks_expression.py
python module07_queues.py
python module08_linked_lists.py
python module09_trees_graphs.py
python module10_hash_table.py

```
